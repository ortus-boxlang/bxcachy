# BxCachy v0.9.0: Modern catalog and Mac keyboard toggle

- Existing selected defaults retained. New macOS-style apps added as **optional** curated entries.
- AUR source candidates for Zap, GrokBot, Herder, tmog, and selected desktop clients are **unverified**. Do not auto-install until exact AUR package identity is confirmed.
- `bxcachy mac-keys on|off|toggle|status`: session-only swap of physical left Alt and left Super via Hyprland XKB. Available in the quick menu. No KDE or permanent keyboard configuration changes. This does **not** turn Ctrl+C into Command+C in Linux apps.
- `catalog/app-picker.html`: offline searchable selection tool, grouped by type and category, one-line descriptions, JSON export. Screenshot preview supported when verified screenshot_url is provided; no invented images.
- Source mappings and some package names are provisional and require CachyOS validation.
